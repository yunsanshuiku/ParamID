开始使用 ParamID
离线辨识 · 已经有实验文件
  1. 导入 CSV / TSV；也可以先点击“ARX 仿真”体验。
  2. 使用 time, input1, input2, output1, output2 表头自动识别通道。无表头时手动指定时间、输入和输出。
  3. 核对采样周期，选择算法，点击“开始离线辨识”。
  4. 查看验证响应、参数与连续 / 离散数学模型，用结果区按钮导出文件。
在线辨识 · 接收设备采样
  1. 切换“在线辨识”，可先用“一键体验演示”熟悉流程。
  2. 选择串口或跟随 CSV，连接并预览信号；二进制数据选择对应类型和字节序。
  3. 确认输入、输出和采样时间，点击“开始自动建模”。
  4. 完成后点击“停止并保存实验”，保存采样数据和模型。
推荐用多个周期的脉冲或 PRBS 激励。窗口频域方法适用于稳定线性系统；连续模型是基于采样周期与零阶保持假设转换的等效模型。
保存位置与快捷键
桌面版实验目录：%LOCALAPPDATA%\ParamID。导出时可以自行选择保存位置。
