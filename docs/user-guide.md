# 使用与算法说明

以下命令均从仓库根目录运行。

## 导入 input1 / output1 数据包

离线界面统一为“回归仿真”和“ARX 仿真”两个入口，模型结构也只有回归与 ARX 两类。导入 CSV / TSV 后，ARX 识别所有 `input1,input2,…` 和 `output1,output2,…`，也识别单通道 `u/y`、`input/output`。无需另选多通道模型。点击“开始离线辨识”，多输出结果可切换曲线；双输入双输出示例文件仍可直接导入 `examples/multichannel.csv`，真值见同名 JSON。

```csv
time,input1,input2,output1,output2
0.00,0,0,0,0
0.01,1,0,0.02,0.01
0.02,1,1,0.05,0.04
```

上面只是表头格式示意，不足以辨识。推荐记录多个周期的脉冲激励，保留上升沿、下降沿与对象响应过程。脉宽、周期应覆盖关心的动态时间尺度；多输入尽量错开或采用不同周期，避免始终成比例。单一周期也不保证所有高阶动态都得到充分激励。

### 无表头或自定义列名

“文件表头”默认自动判断：首行全部为数值时，保留首行采样并生成 `column1,column2,…`。也可强制指定有 / 无表头。数值列名与首行采样存在歧义时，请显式指定。

在 ARX 的“通道识别”中选择“手动选择信号列”，指定时间列、输入列和输出列（输入输出均可多选）。上方数据预览显示列名与前 3 行采样。不同角色不允许重复，已选时间列从输入输出候选中排除。时间列单位为秒；没有时间列时填写采样周期。独立无表头验证文件应使用相同列布局。

辨识、选模和验证使用原始输入输出信号。低通滤波模块已删除。时间域单输入单输出使用 SISO ARX，时间域多输入或多输出使用联合 ARX + OE；也可选择窗口频域辨识，支持离线多通道和在线单输入单输出。

- 编号按数值排序，可不连续，列顺序不限；大小写及可选的下划线、空格、连字符不影响识别，例如 `Input_2`。同一编号的别名重复会报错。
- `time / time_s / t / timestamp` 视为秒数，自动以全部间隔的中位数确定采样周期，并检查每个间隔的 1% 一致性。不自动重采样。缺少时间列时，需要填写采样周期。
- 所有输入共同作用于每一路输出，不按相同编号一一配对。额外说明列不会作为动态输入；选中的通道必须为有限数值。
- 输入不变化、各输入彼此成比例、时间列异常或有效回归秩不足时，给出原因。无法辨识的独立通道不会靠正则化强行分配系数。
- 结果提供逐输出验证、全部输入输出路径的离散与可用的连续 ZOH 等效传递函数，以及一个等价离散状态空间。连续转换失败时保留离散结果并说明原因。状态空间不保证最小实现，状态不是唯一物理参数。
- 当前数据包格式为 CSV / TSV / 分隔文本，不直接读取 XLSX 或 ZIP。多通道流程用于离线辨识；在线向导及回放仍是原有单输出模型。

每一路输出的模型为 `A_i(q)y_i = Σ_j B_ij(q)u_j + c_i`，`q=z^-1`。搜索 `na=1..6, nb=1..6, nk=0..4`，同一输出中各输入共享分母和起始延迟约定；前导零允许表达不同通道的延迟。每个输出阶次选一个候选进行输出误差优化，同时估计初始滤波状态，最多 70 次优化评估。训练残差超过 4000 点时，优化目标取均匀分布的最多 4000 个残差，动态仿真仍使用每一个输入采样点，没有降低采样频率。

无独立验证文件时按时间 60% / 20% / 20% 分为训练、选模和最终验证；有独立文件时，训练文件按 70% / 30% 划分训练和选模。选模使用自由运行误差加 BIC 形式的复杂度惩罚（启发式评分，不是参数置信度）。缩放、优化与选阶均不使用最终验证数据。若精修没有改善选模结果，允许保留 ARX 候选并明确标注。

这一路线是多输入联合 ARX + OE，不是 N4SID 或带完整噪声模型的 PEM。任意过程噪声、输入噪声、闭环相关噪声下仍可能有偏。只有稳态的验证段不能证明零点和动态阶次准确，软件会提示补充动态实验。

API 可直接向 `/api/offline` 提交 `{"csv":"..."}`，后端同样按表头自动识别；无时间列时另传 `"model":{"kind":"multichannel","sample_time":0.01}`。旧的手工模型需显式保留 `kind=arx` 或 `kind=regression`。

无表头手动通道 API 示例：`{"csv":"...","header_mode":"absent","model":{"kind":"multichannel","time":"column1","inputs":["column2","column3"],"outputs":["column4"]}}`。`header_mode` 可为 `auto/present/absent`，独立验证文件另有可选 `validation_header_mode`。

## 辨识得到的数学模型

结果区底部的“辨识得到的数学模型”会直接代入本次参数，离线和在线均支持：

- 线性回归：显示 `y[k] = θ1 phi_1[k] + … + c`，逐一对应实际特征列。预先计算的非线性特征仍按特征本身解释，不自动生成连续传递函数。
- ARX：显示数值差分方程、离散传递函数 `G(z)`、采样周期、输入延迟和常值截距。
- 展开“等价状态空间表示”可查看状态定义及具体 `A、B、C、D、g、h`，满足 `x[k+1] = A x[k] + B u[k] + g`、`y[k] = C x[k] + D u[k] + h`。状态由输入输出的历史值组成，可能不是最小实现，也不直接代表物理状态。

例如参数 `a1=0.82, b0=0.35, nk=1, c=0.04` 对应 `y[k]=0.82 y[k-1]+0.35 u[k-1]+0.04`，输入通道传递函数为 `G(z)=0.35 z^(-1)/(1-0.82 z^(-1))`。常值项保留在差分方程和仿射状态方程中；传递函数表示零初始条件下输入对输出的贡献，不把截距并入输入通道分子。

公式显示 8 位有效数字，JSON 中 `mathematical_model` 的数值系数保留完整精度。传递函数数组采用 **z^(-1) 的升幂次序**：分母 `[1,-a1,…]`，分子在输入系数前补 `nk` 个零。采集向导还导出 `acquisition_channels`，说明标准化输入输出对应的源列、单位和倍率。

“模型公式 TXT”可直接下载表达式与矩阵；原有模型 JSON、离线报告及采集实验 ZIP 的模型/报告也包含数学模型。在线公式随当前参数更新，停止后保留最后一组结果；尚未完成自动定阶时只显示等待提示。在线传递函数采用当前系数快照，不把整段参数变化过程当成固定线性时不变系统。

### 同时输出连续时间等效模型

ARX 结果现在自动尝试生成 **连续传递函数 `G_c(s)` 与连续状态方程**。这一步使用已有离散辨识系数和采样周期，在零阶保持（ZOH，输入每个采样周期内保持不变）假设下进行转换。它没有另外拟合一套连续测量数据，也不能唯一确定真实连续对象。回归模型未定义动态结构时显示“不适用”。

转换使用主值矩阵对数，并检查连续结果重新 ZOH 离散化后是否与离散动态核心一致；误差阈值为 `1e-8`。该一致性误差用于核对数值转换，不是实验数据拟合误差。存在显著复对数、极点过于接近零、严重病态或不支持的输入滞后结构时，显示原因并保留原离散结果，不强行取复数模型的实部。

连续纯延迟与离散 `nk` 不直接等同。例如 `y[k]=0.82 y[k-1]+0.35 u[k-1]`、`Ts=0.01 s` 对应的无纯时延一阶 ZOH 等效模型满足 `A_c=ln(0.82)/Ts`、`B_c=0.35 A_c/(0.82-1)`，因此 `G_c(s)=B_c/(s-A_c)`。其 `nk=1` 来自采样动态关系，不会自动加上 `exp(-Ts*s)`。

若分子最末非零滞后为 `m`、分母有效阶数为 `n`，转换尝试分离最少 `d=max(0,m-n)` 个整体延迟；只有不会引入超前输入时才继续，输出 `exp(-d*Ts*s)`。这是一种明确的等效表示约定，未估计小于采样周期的时延。连续状态采用可观测规范形坐标，与离散输入输出滞后向量不同；偏置通过 `g_c、h_c` 保留，积分环节也不通过除以零频分母求平衡偏置。

JSON 的 `mathematical_model.continuous_model` 包含 `available / unavailable / not_applicable` 状态、转换方法、假设、连续矩阵、纯延迟和一致性误差；连续传递函数数组按 **s 的降幂次序**排列。TXT、离线报告、采集 ZIP 同步保存这些信息。在线每个结果快照使用当时系数重新转换，有限缓存避免重复计算同一组参数。

## 在线采集：普通用户操作

**无需硬件体验：** 点击在线页的“一键体验演示”，等待约 400 个初始采样后查看自动推荐结构与模型曲线。演示模拟 100 Hz 数据，仅用于操作与算法验证，不代表实时性能认证。

**USB 串口：** 插入设备并刷新设备列表，选择 COM 端口；首次展开“连接设置”核对波特率等参数。点击“连接并预览”，选择输入、输出列并核对物理含义。输入名称、单位、标定倍率及时间设置可在通道详情中配置。勾选核对完成后点击“开始自动建模”。

**二进制数据（double 等）：** 在“设备发送的数据格式”中选择“二进制 · 选择数值类型”，选择 double/float64、float/float32 或 uint8/16/32/64、int8/16/32/64，按实际发送顺序填写通道名称，并选择大小端。例如依次发送两个小端 double 输入、输出，就填写 `input1,output1`，一帧为 16 字节。时间也在数据中时，把时间列名称放在对应位置。无需文字编码和 CSV 表头。

有固定帧头、帧尾时展开填写十六进制字节，软件按“帧头 + 固定长度载荷 + 帧尾”接收；没有帧头时先连接软件，再从完整帧的起点开始发送。串口的一次 read 不等于一帧，软件处理拆包与粘包。没有标记/校验的连续字节流不能自动判断通道顺序或恢复任意错位。

**可编程解码：** 混合类型、结构体填充、比例换算及打包位字段选择“二进制 · 可编程解码”。指定载荷长度，逐行输出通道，例如 `time_s = u32(0) * 0.001`、`input1 = f32(4)`、`output1 = i16(8) * 0.01`，对应 10 字节载荷。表达式使用载荷内偏移，不含帧头、帧尾。`bits(0,6)` 可读取真正的 6 位无符号字段；完整语法及校验例子见 [二进制解码说明](binary-decoder.md)。

“试解码”提供双通道 double、带时间 double、混合数值、打包 uint6 和校验示例，也可粘贴实际收到的十六进制字节核对解码数值，无需连接硬件。连接后展开“二进制接收诊断”可查看字节数、帧数、待拼接字节及最近的原始字节。帧失配、非有限数值或校验失败会结束该实验，避免丢样后继续使用错误时间轴。

**文本 CSV：** 选择文本模式，设备发送带表头的逐行数值 CSV，例如：

```csv
time_s,input_v,output_rad_s
0.00,1.0,0.0
0.01,1.0,0.3
0.02,0.5,0.6
```

文本模式支持 UTF-8 / GB18030，逗号 / 分号 / Tab；每行以换行结束，所有字段必须是有限数值。若设备不发送表头，可在连接设置中填写列名。重复表头、列数错误、非法数字和乱码会停止该实验，不会静默丢弃后继续拟合。仅接收数据，不向设备发送控制指令。二进制模式需要配置确定的定长帧结构；本版不支持任意变长协议、CAN、UDP 或厂商采集卡 SDK。

**跟随 CSV：** 选择采样软件正在持续追加的本机文件，点击连接。文件选择会打开桌面原生对话框，也可展开填写完整路径。连接时仅读取末尾最多 64 KiB 供预览；开始建模后只使用新增完整行，不把整个历史文件当作实时采样。写入软件应及时 flush，并允许共享读取。覆盖、截断、重新创建文件会结束当前实验。

**采样时间：** 默认从设备时间戳估计周期，并检查 1% 等间隔容差；支持秒、毫秒、微秒。没有时间列时，必须核对并填写设备实际固定采样周期，此时无法检测设备端丢样。网络/串口到包间隔不会被用作采样周期。单位不自动猜测，倍率由设备标定或用户确认。

**模板与保存：** 在“保存为设备模板”中填写名称并保存。模板记住来源、串口参数、二进制类型/字节序/帧结构/解码表达式、通道含义、单位、倍率及时间配置。点击“停止并保存实验”会停止接收、处理完已接受队列、保存文件并下载 ZIP。切换离线/高级模式也会结束采集并保存在本机；刷新后可回到在线页查看仍在运行的采集。

桌面版实验保存在 `%LOCALAPPDATA%\ParamID\acquisitions/<实验编号>/`；开发服务默认使用 `outputs/acquisitions/<实验编号>/`：

| 文件 | 内容 |
| --- | --- |
| `raw_samples.csv` | 开始建模后接受的全部源数值字段（不是串口逐字节抓包） |
| `samples.csv` | 换算后的 `time_s,u,y`；物理含义、单位与倍率见元数据 |
| `predictions.csv` | 定阶成功后全部在线一步预测与误差；初始数据不回填为历史预测 |
| `model.json` | 当前参数、结构、候选比较与数值诊断；不足以建模时参数为空 |
| `metadata.json` | 数据源、通道、计数、停止原因及被拒绝的时间异常/溢出样本 |
| `report.md` / `experiment.zip` | 实验说明 / 完整打包下载 |

同一进程最多一个采集连接。预览 120 点，队列 8,192 点，绘图保留 2,000 个预测；每个实验最多 1,000,000 个接受样本，日志总量到 512 MiB 后停止并排空此前队列（因此最终文件可略大）。队列溢出、时间中断、设备断连或磁盘错误均显示明确原因；区分已接受、已保存和已用于建模计数。记录上限不会自动删除以前的实验。

## 自动定阶规则

### 窗口频域辨识（0.7.0）

离线动态模型的“离线求解器”选择“窗口频域 · Welch H1”；简单在线在“核对输入与输出”选择同名算法；高级 CSV 回放 / HTTP 选择“窗口频域 · 滑动窗口更新”。选择频域后点击 ARX 仿真会载入含噪频域示例，仍保留回归与 ARX 两个示例入口。

- Welch 分窗平均，默认 Hann 窗、256 点分段、50% 重叠。窗内去均值只用于频谱计算，不改动或滤波原始采样。
- 联合估计 `H1 = S_yu S_uu^-1`；多输入谱奇异或输入能量不足的频点被排除，至少保留 12 个有效频点。DC 与奈奎斯特点不参与动态拟合，常值偏置单独估计。
- 搜索 na=1–6、nb=1–7、nk=0–10，最多 462 个结构。缩放复数最小二乘初始化，稳定反射系数参数化优化频响。候选参数只用训练段；按选模段自由运行误差和参数复杂度选阶。
- 离线仍采用 60/20/20 时间划分，或主文件 70/30 加独立验证文件；显示原始输出验证、离散传递函数、状态空间和可用的 ZOH 连续等效模型。频域结果统一按传递矩阵返回，SISO 是 1×1。
- 在线默认最近 2048 点，每增加 512 点更新一次；每窗前 75% 拟合、后 25% 选模。首次自动定阶后固定结构，只更新参数。第一次 2048 点不追溯显示在线预测；后续曲线用当前样本到来前的模型。更新失败保留上次模型并显示原因、模型年龄与下一次更新时刻。
- 在线窗口至少为频谱分段点数的 4 倍。分段 64–2048 点，在线窗口 512–16384 点，更新间隔 128–8192 点且不超过窗口。离线训练段至少包含 4 个重叠窗，多输入时至少为输入数加 2 个。
- 结果显示输入到所选输出的频响幅值、相干度和频率间隔；多输入报告联合相干度。条件数和秩来自选定模型的缩放频域残差雅可比，排除单独估计的截距，不能代替参数置信区间。
- 适用于稳定线性系统、准确输入和与输入不相关的输出噪声。H1 不自动消除输入测量噪声或闭环偏差；积分/不稳定系统不在本方法支持范围内。有限窗有泄漏和分辨率误差，即使无噪声也不保证精确恢复系数。

更多原理、配置和窗口选择见 [窗口频域辨识](frequency.md)。低通模块、开关和滤波导出均已移除；旧请求启用 `output_filter` 会明确报错，防止静默改变实验。以前保存的实验文件不修改。

### 时间域 ARX 阶次与验证划分

选择 ARX 并映射时间、输入和输出列后，软件默认自动比较 **704 个结构**，不再要求填写 na、nb、nk。结果页给出推荐结构、输入延迟对应的秒数、候选误差和实际数据划分。

1. 所有候选从共同的第 18 个原始样本开始比较，前 17 点用于提供公平一致的历史。每个候选使用相同训练段与选模段。
2. 单文件的有效样本按时间约 60% 训练、20% 选模、20% 最终验证；有独立验证文件时，主文件按 70% / 30% 划分训练和选模，第二份文件仅作最终验证。
3. 每个候选只用训练段拟合；以选模段的**自由运行 RMSE**筛选。误差不超过最小值约 2% 时，优先选择参数更少的模型，再按误差排序。无噪声数据另有相对输出尺度 1e-10 的数值并列容差。
4. 自动选模排除秩不足、缩放后条件数超过 1e10、样本数不足或数值发散的候选。自动模式不会使用岭回归的先验惩罚来掩盖数据秩不足。
5. 不使用最终验证数据定阶，也不在选择结构后把选模段重新加入拟合。触及搜索上限时给出提示。

“最优”指当前搜索范围、选模规则和数据条件下的推荐结构，不保证等于真实系统的唯一物理阶数。自动离线定阶至少需要 120 个等间隔样本；数据噪声、输入激励和工况仍然决定可辨识程度。

在线 ARX 使用截至当前时刻的初始 400 点进行 70% / 30% 训练/选模。激励不足时每增加 200 点自动重试，最多保存最近 1,200 点用于定阶。成功后固定阶次和延迟，RLS 持续更新系数；本版不在运行中反复切换模型阶次。

初始数据在定阶后用于内部 RLS 初始化，**不追溯展示为此前的在线预测误差**。界面与在线 CSV 仅展示定阶完成后的真实更新前预测。自动 ARX 的特征尺度也由初始已观测数据建立，无需用户按未知参数数填写尺度。

API / CLI 默认 `order_mode="auto"`。需要复现旧的固定结构实验时，可显式传入 `order_mode="fixed"` 和模型 `na/nb/nk`；固定结构仍支持 nk=0～50。界面仅提供自动模式。

线性参数模型为

\[
y_k=\varphi_k^\mathsf{T}\theta+v_k.
\]

例如机械系统的 `acceleration, velocity, position` 可以构成特征，输出列为力，以估计对应的质量、阻尼、刚度。前提是输入力、信号单位、轴侧、扰动与模型假设正确，且数据能区分这些参数。

用户自定义特征需提前计算到 CSV；本版不会执行输入的 Python 表达式，也不会自动对带噪位置求导。

ARX 的符号约定为

\[
y_k=\sum_{i=1}^{n_a}a_i y_{k-i}
 +\sum_{j=0}^{n_b-1}b_j u_{k-n_k-j}+c.
\]

`a_i` 采用上式中的正号约定；输出参数顺序是 `a1...ana, b0...b(nb-1), intercept`。ARX 系数通常不能直接解释为质量、电阻等独立物理参数。

## 数据与数值要求

- CSV / 分号分隔 / Tab 分隔，支持有表头与无表头；浏览器读取 UTF-8 或 GB18030。CLI 示例按 UTF-8 读取。
- 离线导入每个文件不超过 50,000 个样本、128 列、12MB；每个模型不超过 32 个参数（含截距）。采集向导限制见上文。
- 选中列必须是有限数值，不会静默删除缺失、重复或乱序样本。
- 时间列单位是秒，必须严格递增；ARX 时间间隔相对用户填写的 Ts 偏差不得超过 1%。
- 无时间列时按样本序号和填写的 Ts 构造时间，无法检查真实采集抖动或丢包。
- 离线信号单位需事先统一；采集向导可以按用户确认的倍率换算，不自动推断物理单位。独立验证文件须使用同一列名、单位和采样周期。
- 离线 LS/WLS 拒绝秩不足的数据。岭回归允许正则化解，但会提示物理参数不能因此被认定为可唯一辨识。
- 岭回归惩罚的是训练数据 RMS 缩放后的系数，截距不受惩罚；不同实验中的 α 不能脱离尺度直接比较。
- WLS 的权重列可留空，默认选择“不加权（普通最小二乘）”；留空时采用等权重，实际按 LS 计算，结果标签、JSON 与报告均显示 LS。选中权重列时，该列的训练权重必须为有限正数，含义为相对观测方差的倒数；权重整体倍乘不改变拟合。已选择但数值无效的权重列仍会报错。
- 自动 ARX 在线尺度由初始已观测数据确定后固定；线性回归/固定阶次 API 默认尺度为 1，量纲差异大时可输入逐参数典型幅值。
- RLS 的 P 是单位观测噪声约定下的信息逆矩阵，不自动构成经校准的参数置信区间。

自动 ARX 使用统一 17 点历史后划分训练/选模/验证；固定模型按其自身预热长度划分。一步预测可使用验证段此前的实测输出；自由运行仅以验证段之前的历史初始化，随后递推使用预测输出。独立文件使用选定模型自身所需的开头历史进行预热，不参与训练或定阶。

拟合度为 `100*(1 - ||y-yhat|| / ||y-mean(y)||)`，可以为负；输出近似常值时未定义。在线 RMSE 是最近最多 2,000 个**更新前预测误差**的统计量，不能当作独立验证精度。

## 实时样本接口

以下是“高级 / 开发者接入”的 HTTP 会话接口。新手向导已内置串口 CSV 与文件跟随，无需手动管理这些接口。自定义采集程序应先完成通道同步及标定，再按序提交数据。

创建会话：`POST /api/session/create`

```json
{
  "model": {
    "kind": "regression",
    "output": "y",
    "features": ["x1", "x2"],
    "time": "time_s",
    "sample_time": 0.01,
    "intercept": true
  },
  "forgetting": 0.995,
  "p0": 1000,
  "scales": [1, 1, 1]
}
```

响应含 `session_id` 和 `next_sequence`。可选 `theta0` 按参数顺序给出物理尺度下的初始值；它是初值，不能代替完整递推状态恢复。

对于 `model.kind="arx"`，默认开启自动定阶，模型中不需要 `na/nb/nk`，也不要传 `scales/theta0`；这两项在未知结构时维度尚未确定。创建响应的 `order_selection.status` 为 `collecting`，参数表为空；初始定阶成功后变为 `selected` 并返回推荐结构。

提交样本：`POST /api/session/push`

```json
{
  "session_id": "替换为返回的会话 ID",
  "sequence": 0,
  "samples": [
    {"time_s": 0.00, "x1": 1.2, "x2": -0.2, "y": 3.44},
    {"time_s": 0.01, "x1": 0.7, "x2": 0.5, "y": 1.70}
  ]
}
```

- 每批 1～256 点，`sequence` 是该批首样本的零基序号，ARX 预热点也占用序号。
- 成功后按 `next_sequence` 发送下一批。响应 `series` 仅含本批新增更新，`history_mode="append"`。
- 批次中任一点错误，整批不提交；重复批次和错误序号会被拒绝。
- 网络超时后必须先读快照确认服务器是否已经提交，再决定从哪个序号恢复，不能盲目重发。
- `GET /api/session?id=会话ID` 返回完整快照，`series` 是最近最多 2,000 次更新，`history_mode="replace"`。
- `POST /api/session/delete`，请求体 `{"session_id":"..."}`，结束会话。
- 同时最多 8 个会话，闲置一小时过期。默认只监听 `127.0.0.1`。

本项目的模拟采集客户端可以接入界面已创建的**新会话**：

```powershell
python scripts/stream_example.py --session 替换为界面会话ID --csv examples/regression.csv --period 0.01
```

将脚本中的 CSV 迭代器替换成设备读取逻辑即可开发相应适配器。该示例仍是仿真采集，不代表已完成硬件通信验证。
