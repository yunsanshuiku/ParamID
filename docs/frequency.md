# 窗口频域辨识

本方法辨识稳定线性时不变系统。输入输出保持原始采样时间和单位，不使用输出低通或差分。它是一种频域估计方法，内部仍用数值最小二乘求解有理传递函数的系数；与时间域 ARX 的回归目标不同。

## 数学模型

对训练段分成长度为 L、重叠 50% 的窗口，每段去均值后乘 Hann、Hamming 或矩形窗。计算各段 FFT：U_r(f)、Y_r(f)。平均得到：

\[
S_{uu}=\frac1R\sum_r U_rU_r^H,\quad
S_{yu}=\frac1R\sum_r Y_rU_r^H,\quad
\widehat H_1=S_{yu}S_{uu}^{-1}.
\]

多输入时 U 是列向量，必须联合解输入谱矩阵。某频点输入谱奇异、条件数超过 1e8，或输入能量低于峰值的 1e-6 时，不使用该点；不是给奇异矩阵加大正则化后强行分离输入。至少要求 12 个有效频点。该能量门限也会舍弃很弱的有效频率，因此激励设计仍然重要。

每路输出使用共同分母，拟合

\[
G_{ij}(z)=\frac{z^{-n_k}\sum_{\ell=0}^{n_b-1}b_{ij\ell}z^{-\ell}}
 {1-\sum_{\ell=1}^{n_a}a_{i\ell}z^{-\ell}}.
\]

搜索 na=1…6、nb=1…7、nk=0…10。复数残差拆为实部和虚部，用列缩放 SVD 求解三个 SK 初始化迭代；每种分母阶次最多精修一个候选，使用 tanh 反射系数保持离散极点在单位圆内，最多 60 次优化评估。拟合按输入谱能量加权，不把低相干度频点静默筛掉。离线按选模段自由运行均方误差的对数加 p·log(N)/N 复杂度惩罚选择结构；真实阶数不一定在候选范围内。

频谱不含 DC 和奈奎斯特点。偏置在确定动态之后，用训练数据的差分方程残差均值估计，不假设整段已经到达稳态。界面中的“条件数”是最终模型频域残差雅可比列缩放后的局部条件数；有效秩只含动态系数，不含单独估计的截距。

## 如何选择窗口

- **默认**：Hann 窗，每段 256 点，重叠 50%。在线保留 2048 点，每增加 512 点更新一次。窗长是采样点数，不是电脑收到数据包的个数。
- **频率间隔**：Δf=1/(L·Ts)。Ts=0.01 s、L=256 时约为 0.391 Hz。若主要动态远低于该频率，需增大分段点数，同时提供更长的数据记录。显示的间隔不是独立频率分辨率保证，窗函数主瓣也会平滑频谱。
- **Hann / Hamming**：适合通常的非同步、含噪数据，可以减轻边界泄漏，但不完全消除有限窗偏差。
- **矩形窗**：适合周期输入和稳态周期输出均与窗口同步，窗口包含整数个周期的情况。仅仅“信号周期性”不够，还需要确认同步和暂态已消退。
- **激励**：PRBS、不同脉宽和间隔的脉冲、多正弦通常比单次阶跃更适合频响辨识。每个输入都需要独立的有效激励。重复同一周期不会自动覆盖所有动态频率。
- **慢系统**：先保证窗口覆盖多次主要动态变化，再考虑刷新速度。增大窗口降低响应时变系统的速度；这里不能承诺最优窗口自动选择。

相干度衡量频率上的线性关联。多输入时显示联合相干度，并不是单条传递路径的参数置信度。高相干度、好看的拟合曲线，都不能保证每一个零极点或多项式系数准确。

## 离线和在线的数据隔离

离线单文件按 60% 训练 / 20% 选模 / 20% 验证。有独立验证文件时，训练文件按 70% / 30% 分训练和选模，另一文件只验证。频谱、缩放、候选参数完全不读取最终验证数据。独立文件预留 16 点历史后开始计分。

在线仅使用已收到的数据。先收满滑动窗口，前 75% 估计频谱与参数，后 25% 比较候选。首次自动选阶后固定结构，随后每到更新间隔重新估计系数。失败时保留上次模型并输出原因、最后成功位置和模型年龄。

第一窗的历史不会追溯显示为实时预测。后续曲线是使用当前样本进入窗口之前已有的模型进行的一步预测，其历史输出项仍为测量值；它不是独立自由运行验证。在线内存最多保留配置窗口和最近 2000 条预测。FFT 和优化在采集消费线程进行，接收线程仍有有界队列，Python 不保证硬实时。

离线支持每类最多 8 路输入和输出。在线串口、CSV 文件跟随、回放、HTTP 频域会话当前均为单输入单输出；二进制可以解码多列，但一次在线会话只选择一路输入和输出。

## API 与导出

离线 `/api/offline` 或在线 `/api/session/create` 顶层：

```json
{
  "algorithm": "frequency",
  "frequency": {
    "window": "hann",
    "segment_length": 256,
    "window_samples": 2048,
    "update_every": 512
  }
}
```

在线采集 `/api/acquisition/start` 把 `algorithm` 和 `frequency` 放在 `channels` 中，设备模板同样保存。原有 RLS 使用 `algorithm: "rls"` 或省略；旧在线 `ls` 请求兼容 RLS。

离线频域统一返回 `model.kind: "multichannel"`，SISO 是 1×1 特例；每路输出的频谱位于 `output_results[i].frequency`。在线频谱与更新状态位于 `frequency`。频响的实部和虚部保留原物理单位，界面展示幅值 dB。相应的模型 JSON 包含谱估计、窗长、相干度和有理模型，结果 CSV 仍保存原始测量输出及模型响应。

提供离散传递函数、状态空间；条件允许时也给出 ZOH 连续等效模型。连续模型由离散模型转换，不是独立连续时间辨识。

低通代码、界面开关和新实验的 `filtered_samples.csv` 均已移除。旧配置若启用 `output_filter` 会报错，需刷新页面并重新保存模板。以前保存的实验不改写。

## 局限和验证

H1 的常见适用条件是准确输入、与输入不相关的输出测量噪声。输入测量噪声、反馈相关噪声、非线性、明显时变和不稳定/积分对象不能仅靠本方法解决。有限分窗使无噪声数据也可能存在估计偏差，不承诺优于所有时间域方法。

复现命令：

```powershell
python -m unittest discover -s tests -q
python scripts/validate_frequency.py
node scripts/ui_smoke.mjs
```

仿真基准使用准确宽带输入、独立输出白噪声和已知二阶稳定系统，固定结构以单独比较噪声偏差。3 个种子的系数相对误差中位数：输出噪声标准差 0.15 时，ARX LS 约 46.5%，窗口频域约 0.66%；无噪声时 LS 接近机器精度，频域约 0.13%。这些是本仿真结果，不代表用户设备精度。完整结果在 `outputs/frequency_validation/benchmark.json`，自动选阶、多通道、因果性和采集归档另由测试覆盖。
